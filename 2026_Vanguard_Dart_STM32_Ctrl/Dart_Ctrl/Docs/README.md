## 系统架构

系统采用清晰的分层设计，确保模块间的低耦合：

```
┌──────────────────────────────────────────────┐
│            应用任务层 (UserTask.c)            │
│      (换弹、扳机、云台控制、通信调度)          │
└───────────┬──────────────────────┬───────────┘
            ↓                      ↓
┌───────────┴──────────┐  ┌────────┴───────────┐
│   电机管理 (CanMotor) │  │  舵机控制 (HX06L)  │
│  (OO类设计, PID计算)  │  │ (多协议支持, CRC)  │
└───────────┬──────────┘  └────────┬───────────┘
            ↓                      ↓
┌───────────┴──────────┬───────────┴───────────┐
│         硬件抽象层 (BSP_CAN, BSP_UART)         │
└──────────────────────┬───────────────────────┘
                       ↓
┌──────────────────────────────────────────────┐
│            STM32 HAL / 硬件外设               │
└──────────────────────────────────────────────┘
```

## 快速开始

### 1. 系统初始化
```c
int main(void) {
    HAL_Init();
    SystemClock_Config();
    
    // 1. 初始化底层计时器
    DWT_Init(168); 
    
    // 2. 初始化UART（自动启动中断接收）
    BSP_UART_Init(); 
    
    // 3. 初始化电机系统
    MotorInit(); 
    
    // 4. 启动RTOS任务
    osKernelStart();
}
```

### 2. 电机控制示例 (面向对象风格)
```c
// 获取电机句柄
MotorTypeDef *yaw_motor = Motor_GetHandle(DM_4310_YAW);

// 设置控制参数
DM_Motor_SetMITParams(yaw_motor, 10.0f, 0.5f, 0.0f);

// 在控制循环中发送
DM_Motor_SendControl(yaw_motor);
```

### 3. UART通信示例
```c
// 检查是否有DART协议包
if (UartModule_HasDartPacket(BSP_UART6)) {
    DartPacket_t pkt;
    if (UartModule_GetDartPacket(BSP_UART6, &pkt)) {
        // 处理数据 pkt.data
    }
}
```

## 核心配置速查

- **CAN波特率**: 1Mbps
- **UART波特率**: 115200 (默认)
- **电机ID分配**: 
  - RM电机: 0x201~0x208 (反馈)
  - DM电机: 0x001~0x005 (MIT模式)
- **调试宏**: 在各个 `.h` 文件中修改 `TestUse` 宏以开启调试输出。

---

## 开发规范

1. **结构体对齐**: 所有通信相关的结构体务必使用 `#pragma pack(push, 1)`。
2. **零拷贝读取**: 优先使用内联函数（如 `Motor_GetHandleFast`）获取指针，避免频繁的内存拷贝。
3. **协议扩展**: 新增串口协议应在 `UartProtocol.c` 的状态机中实现。
