# STM32 飞镖控制系统 (Vanguard Dart)

## 项目概述
本系统是基于 STM32F427IIH 开发的飞镖机器人控制系统。该系统集成了多电机协同控制、高精度传感器反馈、多协议串口通信以及基于 FreeRTOS 的实时任务调度，旨在 15 秒内高效完成 4 次飞镖发射过程。

---

## 核心技术栈
- **硬件平台**: STM32F427IIH (A板)
- **实时系统**: FreeRTOS
- **驱动库**: STM32 HAL, DSP Library
- **通信协议**: CAN (1Mbps), UART (DMA+环形缓冲区), IBUS (遥控器), 总线舵机协议
- **控制算法**: 增量式/位置式 PID, 面向对象电机驱动框架

## 系统架构

系统通过任务间的同步与互斥，实现了从换弹、储能到发射的闭环流程。

### 硬件拓扑与数据流
```text
                                [ 外部输入 ]
                                     |
    +--------------------------------+--------------------------------+
    |                                |                                |
[ 遥控器 IA6B ]                  [ 视觉/上位机 ]                  [ 传感器反馈 ]
    | (IBUS)                         | (UART)                         |
    V                                V                                V
+--------------------------------------------------------------------------+
|                          串口协议解析层 (UartModule)                        |
+--------------------------------------------------------------------------+
                                     |
                                     V
+--------------------------------------------------------------------------+
|                          FreeRTOS 任务调度层                               |
|  +--------------+      +--------------+      +--------------+           |
|  |   换弹任务   | <--> |   储能任务   | <--> |   发射任务   |           |
|  | (RM3508/舵机)|      | (DM3519*2)   |      | (PWM/MG996R) |           |
|  +--------------+      +--------------+      +--------------+           |
+--------------------------------------------------------------------------+
                                     | (PID计算 / 指令下发)
                                     V
+--------------------------------------------------------------------------+
|                          硬件抽象层 (BSP_CAN/UART)                          |
+--------------------------------------------------------------------------+
```

### 任务逻辑流
1. **StateSetTask**: 初始化云台 Yaw 轴 (DM4310) 和扳机射程 (RM2006) 至预设位置。
2. **StoreEnergyTask**: 控制左右 DM3519 电机将拉簧拉至指定动能位置，利用互斥量与换弹任务同步。
3. **LoadTask**: 协同 RM3508 传送带电机与总线舵机，将飞镖精准推送到发射位。
4. **ShootTask**: 触发 MG996R 舵机释放扳机，完成发射。

## 快速开始

### 1. 系统初始化
在 `main.c` 中，系统按序启动硬件与内核：
```c
int main(void) {
    HAL_Init();
    SystemClock_Config();
    
    // 1. 初始化高精度计时器 (180MHz)
    DWT_Init(180); 
    
    // 2. 初始化底层外设与电源管理
    BSP_POWER_Init(); // 开启 24V 使能
    BSP_UART_Init(); 
    MotorInit(); 
    CanFilterCfg();
    
    // 3. 启动应用层任务初始化
    TaskInitFunc();
    
    // 4. 进入 RTOS 调度
    osKernelStart();
}
```

### 2. 电机控制 (OOP 示例)
```c
// 获取电机句柄并下发 MIT 模式指令
MotorTypeDef *yaw = Motor_GetHandle(DM_4310_YAW);
DM_Motor_SetMITParams(yaw, target_pos, target_vel, kp, kd, torque);
DM_Motor_SendControl(yaw);
```

### 3. 总线舵机控制
```c
// 驱动 0x01 号舵机在 500ms 内转动到 500 位置
serial_servo_set_position(&serial_servo_controller, 0x01, 500, 500);
```

## 核心配置速查

- **CAN 波特率**: 1Mbps (CAN1/CAN2)
- **UART 波特率**: 115200 (上位机), 115200 (总线舵机), 115200 (IA6B)
- **电机 ID 分配**:
  - **RM-M3508 (换弹)**: 0x201
  - **RM-M2006 (扳机)**: 0x205
  - **DM-J4310 (Yaw)**: 0x003 (MIT 模式)
  - **DM-S3519 (储能)**: 0x001 (左), 0x002 (右)
- **总线舵机 ID**: 0x01, 0x02, 0x03 (换弹机构)

---

## 开发规范

1. **协议安全**: 所有通信数据帧建议在 `UartProtocol.c` 中通过状态机解析，严禁在中断中进行复杂逻辑处理。
2. **电机安全**: 调试时请务必配置 `config.h` 中的 `SOFT_LIMIT` 参数，防止堵转损坏机构。
3. **实时性**: 任务优先级按 `osPriorityNormal` (发射) > `osPriorityBelowNormal` (换弹) 分配，确保紧急控制响应。
