Code style: C (STM32 HAL + FreeRTOS). Function names are mixed CamelCase/UpperCamel with prefixes (e.g., BSP_UART_Init, UartModule_GetIbusPacket). Macros and enums use ALL_CAPS with underscores. Doxygen-style file headers and block comments are common. UART protocol parsing is in UartProtocol.c; BSP drivers encapsulate ring buffers and HAL callbacks. Docs call out: use #pragma pack(push, 1) for comm structs, prefer zero-copy handle accessors, and add new UART protocols in UartProtocol.c.
