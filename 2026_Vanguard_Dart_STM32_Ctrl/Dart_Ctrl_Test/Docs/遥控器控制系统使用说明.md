# 遥控器控制系统使用说明

## 概述

本文档描述飞镖系统的遥控器（FS-I6 + IA6B接收机）控制模块的设计与使用方法。

**核心文件**：

- `User/inc/ControlState.h` - 控制状态结构体与API声明
- `User/src/ControlState.c` - IbusTask、ControlTask实现
- `User/src/IA6B.c` - IBUS协议解析

---

## 一、模式状态机

```
┌─────────────────────────────────────────────────────────────────┐
│                        上电初始化                                │
│                            │                                    │
│                            ▼                                    │
│              ┌─────────────────────────────┐                    │
│              │   CTRL_MODE_NORMAL_SINGLE   │◄────────────────┐  │
│              │      （正常单发模式）         │                 │  │
│              └──────────────┬──────────────┘                 │  │
│                             │                                 │  │
│                   单发流程完成后                               │  │
│              ShootTask调用StartDebugWindow()                  │  │
│                             │                                 │  │
│                             ▼                                 │  │
│              ┌─────────────────────────────┐      20s超时     │  │
│              │   CTRL_MODE_DEBUG_TIMER     │─────────────────►│  │
│              │     （调试窗口模式）          │                 │  │
│              └──────────────┬──────────────┘                 │  │
│                             │                                 │  │
│                    SWB=0 拨下                                  │  │
│                             │                                 │  │
│                             ▼                                 │  │
│              ┌─────────────────────────────┐                 │  │
│              │      手动控制生效            │      SWB=1      │  │
│              │   ControlTask下发电机命令    │─────────────────┘  │
│              └─────────────────────────────┘                    │
└─────────────────────────────────────────────────────────────────┘
```

### 模式说明

| 模式     | 枚举值                    | 触发条件        | 行为                       |
| -------- | ------------------------- | --------------- | -------------------------- |
| 正常单发 | `CTRL_MODE_NORMAL_SINGLE` | 默认状态        | 任务流程接管电机，忽略摇杆 |
| 调试窗口 | `CTRL_MODE_DEBUG_TIMER`   | 单发完成后20s内 | 允许SWB=0进入手动控制      |

**重要**：调试窗口外，SWB=0 无效，不会进入手动模式。

## 二、通道映射

### 2.1 摇杆与开关分配

| RawChannel | 遥控器位置 | 类型     | 控制目标 | 电机       |
| ---------- | ---------- | -------- | -------- | ---------- |
| `[0]`      | 右摇杆左右 | 回中     | YAW角度  | DM4310     |
| `[1]`      | 右摇杆上下 | 不回中   | 储能位置 | DM3519 L/R |
| `[2]`      | 左摇杆上下 | 不回中   | 扳机位置 | RM2006     |
| `[3]`      | 左摇杆左右 | 回中     | 3508位置 | RM3508     |
| `[4]`      | SWB        | 两段开关 | 模式切换 | -          |
| `[5]`      | SWC        | 三段开关 | 扳机覆盖 | RM2006     |

### 2.2 控制逻辑

#### 回中摇杆（增量式）

```c
// 归一化：norm = (raw - 1500) / 500，死区 ±5%
// 目标更新：target += norm * weight * dt
```

#### 不回中摇杆（三段式）

```c
// 方向判定：raw > 1700 -> +1, raw < 1300 -> -1, 否则 0
// 目标更新：target += dir * weight * dt
```

#### 开关状态

- **SWB**：`1000 -> 1`（正常），`2000 -> 0`（手动）
- **SWC**：`1000 -> 1`，`1500 -> 0`（扳机上），`2000 -> -1`（扳机下）

## 三、任务架构

### 3.1 任务列表

| 任务名          | 优先级  | 周期     | 栈大小 | 职责                           |
| --------------- | ------- | -------- | ------ | ------------------------------ |
| IbusTask        | High    | 5ms      | 512B   | 解析IBUS，更新`g_ControlInput` |
| ControlTask     | Normal  | 10ms     | 1KB    | 计算目标增量，下发电机命令     |
| StoreEnergyTask | Normal1 | 事件驱动 | 512B   | 储能电机状态机                 |
| ShootTask       | Normal  | 事件驱动 | 512B   | 舵机发射控制                   |
| StateSetTask    | Normal  | 一次性   | 2KB    | 初始化YAW和扳机位置            |

### 3.2 数据流

```
┌──────────┐    g_ControlInput    ┌─────────────┐    电机命令    ┌──────────┐
│ IbusTask │ ──────────────────► │ ControlTask │ ────────────► │  电机    │
└──────────┘                      └─────────────┘               └──────────┘
     │                                   │
     │ IA6B_ProcessIbusPacket()          │ DmMotorSendCfg()
     │ 解析RawChannel[]                   │ RmMotorPID_Calc()
     ▼                                   ▼
┌──────────┐                      ┌─────────────┐
│ UART DMA │                      │g_ControlState│
└──────────┘                      └─────────────┘
```

## 五、典型调试场景

### 5.1 完整流程

```
1. 上电
   └─► StateSetTask 设置初始 YAW 和扳机位置
           │
2. 事件组就绪
   └─► StoreEnergyTask 开始储能状态机
           │
3. 储能完成（到达扳机位置）
   └─► ShootTask 释放舵机，发射飞镖
           │
4. 发射完成
   └─► 调用 ControlState_StartDebugWindow()
       ├─► 同步目标值与电机当前反馈（避免突跳）
       └─► 开启 20s 调试窗口
           │
5. 调试窗口内
   └─► 拨下 SWB → 遥控器接管电机控制
       ├─► 右摇杆左右 → 调节 YAW
       ├─► 右摇杆上下 → 调节储能电机
       ├─► 左摇杆上下 → 调节扳机（或用SWC覆盖）
       └─► 左摇杆左右 → 调节 3508
           │
6. 调试结束
   └─► 20s 超时或拨回 SWB → 恢复正常模式
```

### 5.2 手动调试操作

1. **等待调试窗口**：单发完成后自动开启
2. **拨下SWB**：进入手动控制模式
3. **使用摇杆**：
   - 右摇杆左右：调节云台YAW角度
   - 右摇杆上下：调节储能电机位置
   - 左摇杆上下：调节扳机位置
   - 左摇杆左右：调节3508换弹位置
4. **使用SWC**：
   - SWC中位(0)：强制扳机上移
   - SWC下位(-1)：强制扳机下移
5. **拨回SWB**：退出手动模式

## 六、保护机制

### 6.1 模式互斥

- 调试窗口外，SWB=0 无效
- 只有在 `debug_window_active` 为 true 时才允许手动控制

### 6.2 内层循环检测

```c
// StoreEnergyTask 内部等待循环可被手动模式打断
while (temp)
{
    if (ControlState_IsManualOverride()) break;
    // ...
}
```

### 6.3 目标同步

```c
// 进入手动模式瞬间，目标值对齐电机当前反馈
if (manual_override && !prev_manual_override)
{
    SyncTargetsWithMotorFeedback();
}
```

## 八、故障排查

| 现象            | 可能原因       | 解决方法                              |
| --------------- | -------------- | ------------------------------------- |
| SWB拨下无反应   | 不在调试窗口内 | 等待单发完成后再操作                  |
| 电机突跳        | 目标值未同步   | 检查 `SyncTargetsWithMotorFeedback()` |
| 摇杆无响应      | IBUS数据无效   | 检查 `g_ControlInput.data_valid`      |
| 调节速度太快/慢 | 权重参数不合适 | 修改 `WEIGHT_*` 宏定义                |
| 电机到达极限    | 限幅参数错误   | 修改 `*_MIN/*_MAX` 宏定义             |
