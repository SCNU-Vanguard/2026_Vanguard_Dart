## 📖 简介

本文档整理了 **RoboMaster 飞镖触发装置 2** 的串口通信协议规范。通过本协议，主控端（PC）可以读取飞镖触发装置的传感器状态、主板温度，以及对其阵营灯光进行配置。

---

## 🔌 硬件与通信参数

- **通信模式**：半双工串口通信（UART）
- **电平标准**：TTL
- **波特率**：`921600`
- **供电电压**：`5V`
  > ⚠️ **重要提示**：
  >
  > - 由于波特率较高（921600），请确保主控端的串口配置能够支持此速率，以防出现乱码。
  > - 串口默认处于接收状态。当触发装置正确收到指令后，会等待约 **0.1~2 毫秒** 返回数据，随后立即切回接收状态。主控端需注意半双工的收发切换时序。
  > - **配置窗口期**：开机通电后的**前 3 秒**为“设置状态”，必须在此期间下发“阵营设置”命令。

## 📦 数据帧基础结构

所有的下发指令与回复数据均遵循以下帧骨架：
| 字段 | 长度 (Byte) | 说明 |
| :--- | :--- | :--- |
| **帧头** | 1 | 固定值：`0xAA` |
| **命令码** | 1 | 详见下方指令集（如 `0x01` 或 `0x02`） |
| **数据长度 (N)** | 1 | 后续“数据内容”的字节数，取值范围：`0~0xFF` |
| **数据内容** | N | 具体的载荷数据，无数据时 N=0 |
| **校验位** | 1 | CRC-8 校验和（从`帧头`计算至`数据内容`末尾） |
**CRC 校验算法标准：**

- **算法**：`CRC-8/MAXIM-DOW` (或称 DOW-CRC)
- **多项式**：`0x31` (x^8 + x^5 + x^4 + 1)
- **初始值**：`0x00`
- **输入/输出反转**：开启 (Reflect In: True, Reflect Out: True)
- **结果异或值**：`0x00`

## 🛠️ 指令集与交互示例

### 1. 状态及错误码查询 (`CMD_ID = 0x01`)

用于实时查询装置的工作状态、温度及硬件健康情况。
**➤ 主机发送请求**

- **数据长度**：0
- **十六进制示例**：`AA 01 00 58`
  **➤ 触发装置回复响应**
- **数据长度**：3
- **载荷定义**：
  | 偏移量 | 字段名称 | 类型 | 说明 |
  | :--- | :--- | :--- | :--- |
  | Byte 1 | `version` | uint8_t | 固件版本信息 |
  | Byte 2 | `temp` | uint8_t | PCB 主板温度（℃） |
  | Byte 3 | `state` | uint8_t | 状态位（需按位解析，详见下表） |

- **`state` 状态字节按位解析：**

  **Bit 3 (阵营)**：`0` = 红方，`1` = 蓝方

  **Bit 2 (可见光)**：`0` = 熄灭，`1` = 点亮

  **Bit 1 (供电电压)**：`0` = 正常，`1` = 异常/过低

  **Bit 0 (红外灯珠)**：`0` = 正常，`1` = 异常 \* _Bit 4~7_：保留位，忽略

  **💡 真实通信抓包示例：**

  发送 » AA 01 00 58

  接收 « AA 01 03 01 1F 00 89

## _解析：返回数据长度 3 字节。载荷为 `01 1F 00`。表示版本为 `v1`，当前主板温度 `0x1F` (31℃)，状态码为 `0x00` (红方阵营，灯珠未亮，电压/传感器一切正常)。_

### 2. 设置灯光颜色 (`CMD_ID = 0x02`)

开机前 3 秒内用于设定当前飞镖所属阵营。

**➤ 主机发送请求**

- **数据长度**：1

**载荷定义**：`0x00`=红方，`0x01`=蓝方

**十六进制示例**：

设置**红方**：`AA 02 01 00 39`
设置**蓝方**：`AA 02 01 01 67`

**➤ 触发装置回复响应**

**数据长度**：1

**载荷定义**：操作结果状态码

`0x00` = 设置成功

`0x01` = 设置失败

**十六进制示例**：

红方设置**成功**返回：`AA 02 01 00 39`

蓝方设置**失败**返回：`AA 02 01 01 67`
